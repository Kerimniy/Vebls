# Vebls

---

Vebls is way to expose the contents of any web-accessible
folder for browsing and sharing.

Features
--------

  - **Discrete architecture** frontend and backend on different hosts.
  - **Light and dark themes** to suit personal style.
  - **Custom sort ordering** gives you control of the ordering of your files/folders.
  - **File search** helps you locate the files you need quickly and efficiently.
  - **File downloads** for fetching files in a single action.
  - **File creating, editing and upload** allows creating, editing and upload files.


Configuration
-------------

  1. Copy `.env.example` to `.env`
  2. Edit the configuration values in `.env`
